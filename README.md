# Демо-сайт «Ростовское море» — v8

Версия собрана с учётом последних правок Бахи.

## Что изменено

- в навигацию и быстрые направления добавлен отдельный раздел «Участки»;
- подготовлен полноценный блок под будущую выгрузку участков: расположение, площадь, коммуникации, цена, фото и проверка документов;
- раздел «Готовые дома» разделён на два направления:
  - дома от застройщиков;
  - вторичный рынок;
- вторичный рынок больше не смешивается с объектами из шахматок;
- существующие дома от застройщиков оставлены в отдельной таблице с фильтрами по Ольгинской и Темерницкому;
- цены готовых домов в демо снижены примерно на 2–3 млн ₽ и помечены как предварительные;
- добавлен заметный диапазон «от 6,3 млн ₽»;
- кнопки связи и форма переориентированы на MAX;
- в форму добавлены источник, UTM-метки, страница перехода, honeypot и базовая валидация;
- подготовлен серверный обработчик `send-lead.php` для доставки заявок в MAX;
- исправлено пересечение фильтров проектов и готовых домов;
- сохранены предыдущие правки: контрастные hover-состояния, PNG-изображения проектов, увеличенные планировки и мобильная адаптация.

## Подключение заявок в MAX

В комплекте находятся:

- `send-lead.php` — серверный обработчик;
- `max-config.example.php` — пример конфигурации;
- `site-config.js` — настройки сайта.

Для подключения:

1. Скопировать `max-config.example.php` в `max-config.php`.
2. Вставить токен бота MAX и `chat_id`.
3. В `site-config.js` заменить:

```js
leadEndpoint: ""
```

на:

```js
leadEndpoint: "send-lead.php"
```

Токен хранится только на сервере и не попадает в JavaScript.

## Важно перед публикацией

1. Уточнить окончательные цены готовых домов.
2. Получить выгрузку участков и объектов вторичного рынка.
3. Проверить актуальность статусов домов из шахматок.
4. Подключить MAX по инструкции выше.
5. Указать ID Яндекс Метрики в `site-config.js`.
6. Добавить политику обработки персональных данных.
