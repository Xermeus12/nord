# Демо-сайт «Объект 248»

Рабочая демонстрационная версия, собранная по переписке:

- крупная лаконичная подача без визуального шума;
- направления: готовые дома, стройподряд, ипотека, сделки с недвижимостью, юридическая проверка;
- каталог проектов с фильтрами и модальными карточками;
- демонстрационная шахматка готовых объектов;
- отдельные блоки по White Box и инженерии;
- мобильное меню, адаптив, формы и подготовка целей Метрики;
- контакты: один общий номер, Telegram, MAX, адрес агентства;
- география по Ростову-на-Дону и области.

## Быстрый запуск

Откройте `index.html` в браузере. Для корректной проверки лучше запустить локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Что менять после получения материалов

1. `projects-data.js` — реальные проекты, цены, площади, планировки и статусы.
2. `assets/*.svg` — заменить на живые фото и рекламные макеты.
3. `site-config.js` — название, контакты, номер счётчика Метрики и endpoint формы.
4. В `site-config.js` указать `yandexMetrikaId` после создания счётчика.
5. В `leadEndpoint` указать адрес обработчика заявок или подключить Telegram/CRM.

Рабочее название «Объект 248» используется как демонстрационное и легко меняется в `site-config.js`.
