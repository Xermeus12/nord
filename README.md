# Демо-сайт «Ростовское море»

Обновлённая рабочая демонстрационная версия сайта агентства недвижимости.

## Что изменено

- интегрирован логотип «Ростовское море»;
- логотип подготовлен в PNG с прозрачным фоном;
- палитра сайта обновлена под сине-голубую айдентику;
- шесть рекламных макетов застройщика переработаны в аккуратные карточки проектов;
- из исходных макетов отдельно подготовлены изображения домов и планировки;
- добавлены цена, первоначальный взнос и ориентировочный платёж;
- добавлены реальные объекты из двух шахматок: Ольгинская и Темерницкий;
- для готовых домов указаны адрес, площадь, участок, отделка, цена, стадия и ссылки на фото/планировки;
- добавлены фильтры по проектам и локациям;
- обновлены бренд, заголовки, SEO-описание, футер и favicon.

## Файлы

- `index.html` — структура сайта;
- `style.css` — дизайн и адаптив;
- `script.js` — фильтры, модальные окна, формы и динамические списки;
- `projects-data.js` — проекты застройщика и готовые дома;
- `site-config.js` — контакты и настройки сайта;
- `assets/logo-full.png` — полный логотип без фона;
- `assets/logo-mark.png` — знак для шапки и favicon;
- `assets/project-*-house.webp` — очищенные изображения домов;
- `assets/project-*-plan.webp` — планировки.

## Запуск

Можно открыть `index.html` напрямую. Для проверки через локальный сервер:

```bash
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## Важно перед публикацией

1. Уточнить финальные цены и ипотечные расчёты.
2. Проверить актуальность статусов готовых домов.
3. Подключить Яндекс Метрику в `site-config.js`.
4. Подключить отправку формы в Telegram, почту или CRM через `leadEndpoint`.
5. Добавить политику обработки персональных данных.
